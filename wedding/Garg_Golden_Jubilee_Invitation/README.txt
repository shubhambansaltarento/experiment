GARG FAMILY — 50TH WEDDING ANNIVERSARY INVITATION

LOCAL PREVIEW
1. Unzip the package.
2. Open a terminal in this folder.
3. Run: python3 -m http.server 8000
4. Visit: http://localhost:8000

A local web server is recommended because browsers may block audio or downloads when opening file:// directly.
The first tap starts the supplied background music. The Music control can pause/resume it.
The Add to Calendar button downloads an ICS event. Explore Venue opens a Google Maps search.
The two JPEGs and WAV in assets/ are the original uploaded files copied without editing.

HOSTING
Upload the complete folder to any static web host (GitHub Pages, Netlify, Vercel static hosting, or your own web server). Keep index.html and the assets folder together.

EVENT TIME
12:00 PM, 06 December 2026. The ICS file uses India Standard Time (UTC+05:30).
